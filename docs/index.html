For payment leads at software platforms and payfacs who need to know what their gateway hands back. Card orders only, read from public docs. A field a vendor has not documented will not show here.

How a cell gets its code

Every cell is read from the vendor's own docs, API reference, changelog, terms or press release. Nothing is inferred from a marketing sentence.

Vendor pages change. Open the source link before you lean on a cell.

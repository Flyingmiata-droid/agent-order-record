Accepts agent orders

YES documented, field or sentence quoted

(limited, enterprise US; UCP, AP2, ACP)

Accepts: "Adyen Agentic is in limited availability for enterprise merchants operating in the U.S." UCP, AP2, ACP. https://www.adyen.com/press-and-media/adyen-agentic (2026-06-16). Docs: https://docs.adyen.com/online-payments/agentic-commerce (the old agentic-checkout-integration page returned 404 on 2026-11-17).

Agent field in API

PART documented in part

request side, shoppingPlatform and metadata

API field: Agentic Cart API shoppingPlatform ("Agent platform identifier, for example, openai, google, meta"), https://docs.adyen.com/online-payments/agentic-commerce/merchant/agentic-cart-api-integration (modified 2025-12-23). UCP path: optional metadata.agentProtocol, agentSessionId, agentPlatform, https://docs.adyen.com/online-payments/agentic-commerce/merchant/google-agentic-commerce (modified 2026-10-15). No agent flag in the /payments response.

Reaches disputes

SILENT relevant doc read, nothing on it

Disputes: silent. Disputes API v30 (OpenAPI spec, every field listed) and the dispute notifications page were read 2026-11-22: no agent field. Fields include disputePspReference, defenseReasonCode, defenseDocumentTypeCode; webhook additionalData has chargebackReasonCode and disputeStatus. https://docs.adyen.com/risk-management/disputes-api/disputes-api-reference , https://docs.adyen.com/risk-management/disputes-api/dispute-notifications , https://raw.githubusercontent.com/Adyen/adyen-openapi/main/json/DisputeService-v30.json . UCP PAN_ONLY: "Liability shift is not available."

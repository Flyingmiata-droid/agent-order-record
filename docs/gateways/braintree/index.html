Accepts agent orders

YES documented, field or sentence quoted

(ACP, UCP)

Accepts: Agent Ready, ACP via delegated payment tokens, UCP via the Google Pay handler. https://developer.paypal.com/agent-ready/overview (undated, read 2026-11-21; the docs.paypal.ai page now redirects here).

Source pages

  • https://developer.paypal.com/agent-ready/overview (fetched 2026-11-21)

Agent field in API

YES documented, field or sentence quoted

response only, facilitator_details

API field: transaction.facilitator_details.oauth_application_name ("ChatGPT") and oauth_application_client_id in the transaction response. https://developer.paypal.com/agent-ready/agentic-commerce-protocol (re-read by hand 2026-10-15). Reference: https://developer.paypal.com/braintree/docs/reference/response/transaction. The reference describes facilitator_details as third party payment information in general (it names the Grant API, Shared Vault and Google Pay) and does not mention AI agents, so the field is not agent specific and the application name is what says who ordered (read 2026-11-21). UCP path: no agent field documented.
